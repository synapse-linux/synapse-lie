Files on disk

Pass the first shard, not a directory.

For the four-shard Unsloth file, download all four GGUFs from the pinned directory into one local folder. The first shard is small; it is not a complete model. Give its path to --model and LIE finds the remaining shards. Use a fast local SSD for the Antirez Q2 file because its n-gram data is read from that GGUF.

Example model path
LIE_MODEL=/models/UD-Q4_K_XL/Qwen3.8-Flash-Next-UD-Q4_K_XL-00001-of-00004.gguf
build/strix-halo/synapse-lie-server --model "$LIE_MODEL" \
  --model-id qwen3.8-flash-next --port 8000

The quickstart adds context and readiness checks. Choose MTP and vision files from the model-specific table below; published availability and LIE qualification are different statuses.

Model-specific components

Match MTP and vision to the model.

The two main GGUFs package MTP differently. Vision needs a separate encoder in both cases. Read each profile as a complete pairing: a downloadable file is not automatically qualified with every target.

Separate MTP head

Unsloth UD-Q4_K_XL

MTP

Download the separate Unsloth shared Q8_0 predictor ↗ and pass it with --model-mtp. The publisher lists other variants ↗.

Vision

The LIE GPU check used the separate ggml-org Q8_0 projector ↗ with --model-vision. An Unsloth F16 projector ↗ is also published, but was not the file in that check.

LIE exercised this UD-Q4, shared-Q8 MTP and Q8 vision combination in an original-weight functional check ↗. Quality and speed need separate qualification.

MTP inside the main GGUF

Antirez Q2

MTP

The Q2 GGUF contains MTP weights ↗; DS4 enables them without a second download. LIE currently takes an explicit --model-mtp path. Its short Q2 MTP check used an external Unsloth shared Q8_0 head, so use of the embedded predictor is not qualified on LIE.

Vision

Antirez's Qwen setup ↗ specifies the separate ggml-org Q8_0 projector ↗. It is not inside the Q2 GGUF.

LIE has a short Q2 plus external-head functional check ↗. Q2 with its embedded predictor or vision projector has no matching LIE qualification in this build.

Text inference needs only the main GGUF. --mtp-draft-tokens adjusts an admitted predictor; it does not discover embedded weights or download a head. The server reference explains the flags, and the vision guide shows an image request.

Context is a capacity setting

Match context to the model and memory.

--context includes prompt, template and reserved output tokens. The software ceiling is 1,048,576 tokens, but actual memory fit and answer quality are measured separately. Longer contexts may need an explicit --rope-scaling yarn2 or yarn4 profile; use the context guide for admission rules and qualified points.
