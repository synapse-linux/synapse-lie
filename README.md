# Synapse LIE GitHub Pages site

This is the standalone static site for the `gh-pages` branch. It uses no
third-party JavaScript, remote fonts, build step or CDN. The three interactive
charts, context filters, highlight values and accessible data table all read
`data/q2-core-model-flow-2k8k.csv` at runtime. Relative asset paths allow
GitHub Pages to serve it as a project site under `/synapse-lie/`.

## Benchmark provenance

- Source branch: `feature/antirez-compat-audit` at
  `6d0098a0f4ac60c3f13946e5d017f6e206ac168e`.
- Source file: `docs/figures/q2-core-model-flow-2k8k.csv`, copied byte-for-byte.
- SHA-256: `319339b4964fea1d96667d02dfcb5fec1f6850894a71c9e739904869b7ee0bc1`.
- The output-parity JSON is also copied byte-for-byte from
  `docs/figures/q2-core-model-flow-2k8k-quality.json` at that checkpoint;
  SHA-256: `0692edb1899bf328401d8567b00b2e44856a16fce3428732b7d1c0b6f2bd79b5`.
- Method and quality record: `docs/Q2-CORE-MULTI-2K8K.md` in that source branch.
- Twenty original-weight GPU arms on Strix Halo/gfx1151; one run per arm, no
  variance estimate, model loading excluded. This is the model-owned inference
  core, not HTTP throughput. Prefill is serialized and native decode is batched.
- C1 matches the saved single-user reference, while C2–C8 produce different
  continuations. The site must retain this qualification caveat whenever the
  benchmark is shown.

The CSV is data, not generated by the site. To update it, copy a new qualified
CSV, update this provenance and the visible method text, then check the charts
and table against the new rows. The current parser expects the numeric schema
shown in the CSV header and unquoted CSV cells.

## Local check

From this worktree, run `python3 -m http.server 8000 --bind 127.0.0.1`, then
open `http://127.0.0.1:8000/`. A direct `file://` visit may block the CSV fetch.
No GPU, package install or model files are required to view this site.

## GitHub Pages publication

This branch is prepared locally. Publication is a separate action: push
`gh-pages`, then select **Settings → Pages → Deploy from a branch → gh-pages →
/(root)** in the repository. For a project repository named `synapse-lie`
under the `synapse-linux` organization, the usual Pages URL is
`https://synapse-linux.github.io/synapse-lie/`, once GitHub has published it.
The `.nojekyll` file makes GitHub serve the static files directly. No custom
domain is configured. GitHub's [branch publishing instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
describe the required repository settings.

Package commands on the site document prerequisites and are not executed by
the site. Relevant package indexes are linked in each installation panel;
GPU OS/hardware support must be checked in AMD's ROCm compatibility matrix.
