02 / BUILD

Bring your own
machine.

Start with the portable C17 server build. GPU inference adds a supported ROCm stack and an explicit, separately built model adapter.

PACMAN FAMILY

Arch Linux & CachyOS

Install the C17 build prerequisites from your enabled repositories. CachyOS follows the Arch package naming used below; availability can vary by repository snapshot.

CPU build prerequisites
sudo pacman -S --needed base-devel cmake ninja pkgconf git python \
  libuv llhttp json-c curl openssl icu libpng libjpeg-turbo

For the HIP build, the Arch repositories provide rocm-hip-sdk and hipblaslt. Check the AMD OS/GPU support matrix before expecting a qualified GPU run on either distribution.

Arch llhttp package ↗Arch ROCm HIP SDK ↗

DNF FAMILY

Fedora & Red Hat Enterprise Linux

Fedora offers llhttp-devel in its package repositories. On RHEL 9, enable the appropriate development repositories and EPEL 9 first; check package availability for other RHEL releases.

Fedora / RHEL 9 after repositories are enabled
sudo dnf install gcc gcc-c++ cmake ninja-build pkgconf-pkg-config \
  git python3 libuv-devel llhttp-devel json-c-devel \
  libcurl-devel openssl-devel libicu-devel libpng-devel \
  libjpeg-turbo-devel

For RHEL, enable EPEL/CodeReady Builder according to your organization’s policy before running the command. A source build requires pkg-config --modversion libllhttp to succeed.

Fedora / EPEL llhttp-devel ↗EPEL setup ↗

APT FAMILY

Debian & Ubuntu

The package command below applies where libllhttp-dev exists in the configured repositories, including Debian 13 and Ubuntu 25.10/26.04 with Universe enabled.

Debian 13 / supported Ubuntu releases
sudo apt update
sudo apt install build-essential cmake ninja-build pkg-config git \
  python3 libuv1-dev libllhttp-dev libjson-c-dev \
  libcurl4-openssl-dev libssl-dev libicu-dev libpng-dev \
  libjpeg-dev

Debian 12 and Ubuntu 24.04 do not list libllhttp-dev in their standard package indexes. Supply a compatible llhttp development package from an approved source, then verify pkg-config --modversion libllhttp; substituting libhttp-parser-dev will not satisfy this build.

01

Build and verify the C17 server

Run from a fresh Synapse LIE checkout after the distribution prerequisites are installed.

Portable source build
cmake -S . -B build/debug -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build/debug -j1
ctest --test-dir build/debug --output-on-failure
02

Add the optional HIP adapter

This requires C++20, HIP/ROCm, hipBLAS, hipBLASLt, rocBLAS, hipCUB/rocPRIM, ICU, OpenSSL, PNG and JPEG. Match your GPU and OS against AMD’s support matrix. The recorded Q2 run used gfx1151.

Optional model-linked build
python3 -B tools/fetch-gufo.py
python3 -B tools/build-gufo.py new-gufo-label --qwen-only
python3 -B tools/verify-linked.py new-link-label build/new-gufo-label
build/new-link-label/synapse-lie-server --build-info

Build status ≠ model qualification. The portable build and tests do not run original weights. The HIP adapter is an explicit development path; a GPU run requires the project’s coordination and model procedures. See the repository README and AMD ROCm support matrix.
