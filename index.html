    03 / BUILD

    Build for
    your machine.

    For Strix Halo, install the system libraries below and build the GPU-enabled server with one command. Python is not required for this build or to run LIE.

    STRIX HALO · GFX1151

    One command from the repository root.

    On develop, the target fetches the pinned provider source and builds the server and native tools under build/strix-halo/. It reuses a verified provider build on subsequent runs.

    View the develop branch ↗
    GPU-enabled build
    make strix-halo

    System packages by distribution

    Install these once for your distribution, together with its supported ROCm development stack. Package availability varies by release.

    PACMAN FAMILY

    Arch Linux & CachyOS

    Install the native compiler, build tools and C libraries. CachyOS uses the same package names where its enabled repositories provide them.

    Native build prerequisites
    sudo pacman -S --needed base-devel cmake ninja pkgconf git \
  llhttp json-c curl openssl icu libpng zstd lz4

    libuv is bundled by default. For make strix-halo, also install rocm-hip-sdk, hipblaslt and libjpeg-turbo. Check AMD support for your OS/GPU combination.

    Arch llhttp package ↗Arch ROCm HIP SDK ↗

    DNF FAMILY

    Fedora & Red Hat Enterprise Linux

    Fedora offers llhttp-devel in its package repositories. On RHEL 9, enable the appropriate development repositories and EPEL 9 first; check package availability for other RHEL releases.

    Native build prerequisites
    sudo dnf install gcc gcc-c++ cmake ninja-build pkgconf-pkg-config \
  git llhttp-devel json-c-devel libcurl-devel openssl-devel \
  libicu-devel libpng-devel libzstd-devel lz4-devel

    For RHEL, enable EPEL/CodeReady Builder according to your organization’s policy. libuv is bundled by default. make strix-halo also needs ROCm/HIP, hipBLASLt and JPEG development libraries.

    Fedora / EPEL llhttp-devel ↗EPEL setup ↗

    APT FAMILY

    Debian & Ubuntu

    The package command below applies where libllhttp-dev exists in the configured repositories, including Debian 13 and Ubuntu 25.10/26.04 with Universe enabled.

    Native build prerequisites
    sudo apt update
sudo apt install build-essential cmake ninja-build pkg-config git \
  libllhttp-dev libjson-c-dev libcurl4-openssl-dev libssl-dev \
  libicu-dev libpng-dev libzstd-dev liblz4-dev

    Debian 12 and Ubuntu 24.04 do not list libllhttp-dev in their standard package indexes. Supply compatible llhttp development files from an approved source and check pkg-config --modversion libllhttp. libuv is bundled by default; make strix-halo also needs ROCm/HIP, hipBLASLt and JPEG development libraries.

    Debian package index ↗Ubuntu package index ↗

    The one-command entry point is committed on feature/integrate-antirez-qwen at d415d8df. It does not install packages, download model weights or start a server. A successful build alone does not qualify model output or performance. The build guide covers supported ROCm setups and advanced options.
