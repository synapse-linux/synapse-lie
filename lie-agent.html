Current status

Qualified privately. Distribution pending.

The first alpha is integrated in the local development tree at 05f380c9f. Its three component archives have passed the recorded target and recovery tests. Public packages, publication of that source integration and an installation intended for use remain pending.

The commands below apply to a compatible private build with its external dependencies available. There is no public alpha download on this page. Existing server/client documentation retains its own recorded source baseline.

Start

Open a project session.

Run these commands from your project with lie-agent and tmux≥3.2 available. Supply the complete Chat Completions URL and the model ID actually served there.

Private installed build
cd /absolute/project
lie-agent new --name review \
  --endpoint http://127.0.0.1:8000/v1/chat/completions \
  --model configured-model

LIE_AGENT_ENDPOINT and LIE_AGENT_MODEL provide defaults. Credentials come from LIE_API_KEY or the variable named by --api-key-env. Interactive CLI text is deterministic US English.

Persistence

Close the terminal. Return to the project.

Closing the terminal or detaching with Ctrl-b d leaves the owner and current work running in tmux. Return to the same project and run lie-agent: the selector lists live and stopped sessions and shows activity separately from attached terminals. Git worktrees have separate project identities.

Session control
lie-agent
lie-agent sessions
lie-agent attach SESSION_ID
lie-agent stop SESSION_ID
lie-agent resume SESSION_ID

attach reconnects to a verified live owner. resume starts a new owner from durable history after the previous one has stopped; interrupted tools are not replayed automatically. stop and /exit request shutdown. A retained close can keep the owner alive until retirement succeeds.

The first client controls input; additional clients observe. attach --take-control transfers control explicitly. With an enclosing personal tmux session, the client uses a dedicated window.

Inference

One C contract, two connections.

HTTP and direct LIE implement the same backend function table. HTTP uses a configured tool-capable Chat Completions endpoint. Direct mode keeps the model in a session-owned LIE host, using the opt-in transitional Gufo C++/HIP provider. It needs a matching provider build and an absolute model path.

Direct private build
lie-agent new --backend native --model configured-model \
  --model-path /absolute/models/model.gguf --context 8192 --chunk 2048

Model loading begins when work starts; merely opening the selector does not load weights. The native model stays resident between messages and terminal detachments. A build without a provider refuses direct mode explicitly.

Finite mDNS scans can discover LIE endpoints when the SDK feature is enabled. Selection still requires application readiness and model checks; an announcement is not a connected or ready engine. Manual HTTP endpoints remain available.

Effects

Make each operation accountable.

Native tools read, list and search files, inspect Git, apply content-checked patches and run bounded noninteractive commands. Reads are available by default. --allow-write grants patches and --allow-command grants commands for that invocation. Project text and plugins do not grant permission.

The C core validates each call and journals dispatch and outcome. After an interrupted operation, effects SESSION_ID inspects uncertainty and reconcile SESSION_ID --report FILE records an explicit resolution. Reconnection or a restored backup never means the external effect did not happen.

The default state root is $XDG_STATE_HOME/synapse/lie-agent or $HOME/.local/state/synapse/lie-agent; --state-dir chooses a private absolute root. Session removal and retention explicitly reclaim settled ownerless state. Update/rollback uses offline state backups and versioned directories; switching a binary does not downgrade its database.

Extensions

TypeScript, MCP and CodeMode.

Trusted TypeScript plugins

An external Node 22.23.0 runner loads explicitly installed plugins with typed tools, prompt/context contributions and request/tool hooks. The C core reapplies policy after hook rewrites. Process separation manages lifecycle and faults; trusted plugins are not isolated from the user's OS access.

MCP client

Configured stdio or Streamable HTTP peers expose tools, resources and prompts. The qualified profiles are 2025-11-25 and 2026-07-28. Credentials stay outside model prompts and journals. lie-agent is not an MCP server; interactive OAuth and other unqualified MCP extensions remain later work.

CodeMode

The optional pinned Pi codemode 1.4.0 / QuickJS-WASI 3.6.2 component executes JavaScript composition of the common tool registry. A private profile can select root_tools=codemode; every nested C/TypeScript/MCP call retains its own C authorization and durable effect.

Workers have a 32 MiB VM heap, a 60 second deadline and 64 attempted calls. Node/WASM overhead is additional. Worker retirement is observed before releasing the execution slot, and scripts are not automatically replayed after a crash.

Context and observation

Keep history and expose current state.

Inherited and scoped project instructions, plugin contributions and tool results enter a budgeted context. Preflight token counts are explicitly estimated. Recoverable compaction keeps original records; summary requests share the run budget. Real-model summary quality and exact tokenizer preflight remain unqualified.

--jsonl emits structured events. --observe optionally enables authenticated loopback SSE with snapshots, bounded replay and an owner-specific credential. Slow observers do not retain model loans. This observation API is separate from the model endpoint and MCP.

Acceptance

The exact supported alpha scope.

AreaQualified scope
Platform/runtimeLinux x86_64 inside the recorded immutable Fedora43/ROCm image. The full archive needs ICU77; the unmodified Pop!_OS test host lacks it.
Original-weight inferencegfx1150, Qwen3.8-Flash-Next UD-Q4_K_XL; context 8192, chunk 2048, output 1024, C1, noMTP/noVision. Native and HTTP.
Persistent terminaltmux 3.2 target / 3.8 fixtures; owned terminal/SSH closure and same-owner reattach, plus TERM=linux PTYs. Other activities remained running.
Effects/recoveryCrash, SQLite/schema/concurrency, private tmpfs ENOSPC and rollback to a distinct earlier development binary. No published-version downgrade guarantee.
ComponentsBase, optional TypeScript extensions and optional CodeMode archives. Runtime libraries, Node, tmux and models remain external.

Eight strict original-weight cases pass: two controlled C17 tasks × individual/CodeMode × native/HTTP, with exact patches and independent compilation/test checks. Current archive consumers and six TERM=linux PTY cases also pass. Earlier failures remain recorded.

CodeMode used fewer requests/tokens but higher observed wall time in these two fixtures. This is not a broad coding ranking, a general cost saving or an inference-throughput result. Physical VT, last-global-SSH logout and physical persistent-media power loss are outside this acceptance.

The support record includes the immutable image identity and SHA256 for the three private archives. It is metadata, not a public package download.

Roadmap

First alpha and later work have separate gates.

LA01–LA10 are implemented for the alpha; LA11 is qualified in the declared scope. LA12 retains the passed private pilot and pending distribution/operational installation. LA13–LA16 cover advanced gRPC control, continuous discovery and connected-agent liveness, numerical checkpoints/session branches and further ecosystem features such as LSP, browser and GUI.

The autonomous numerical backend remains a separate LIE roadmap. The initial direct adapter is transitional. lie-agent as an MCP server is excluded from the current plan.
