lie-agent

Private alpha · Source and package publication pending

A terminal coding agent with persistent project sessions, controlled tools and durable recovery.

Start a project session

Use a REMOTE build and a configured tool-capable server. Both lie-agent and tmux ≥3.2 must be available.

REMOTE build
cd /absolute/project
lie-agent new --name review \
  --endpoint http://127.0.0.1:8000/v1/chat/completions \
  --model configured-model

LIE_AGENT_ENDPOINT and LIE_AGENT_MODEL supply defaults. Read an API key from LIE_API_KEY or the variable named by --api-key-env.

Return to your project

Close the terminal or detach with Ctrl-b d. The owner and current work continue in tmux. Return to the same folder and run lie-agent to select a live or stopped session. Git worktrees have separate identities.

Session commands
lie-agent
lie-agent sessions
lie-agent attach SESSION_ID
lie-agent stop SESSION_ID
lie-agent resume SESSION_ID

attach reconnects to a live owner. resume creates an owner from durable history after shutdown. Interrupted tools require recovery; they are not replayed automatically. Session activity and attached terminals are shown separately.

Choose the backend at compilation

REMOTE and NATIVE are separate binaries using the same C function-table contract. The build setting is LIE_AGENT_BACKEND; it is not a runtime selector.

REMOTE

The agent uses a configured HTTP Chat Completions endpoint. Model support belongs to that server. No inference core or GPU provider is linked into the agent.

Build remote
cmake -S . -B build/agent-remote -G Ninja \
  -DLIE_AGENT_ONLY=ON -DLIE_AGENT_BACKEND=REMOTE
cmake --build build/agent-remote

NATIVE

The agent links the shared LIE core and one explicitly selected provider. Supply an absolute model file path; no inference server is required.

Use a provider-linked native build
lie-agent new --model configured-model \
  --model-path /absolute/models/model.gguf \
  --context 8192 --chunk 2048

Build with -DLIE_BUILD_AGENT=ON -DLIE_AGENT_BACKEND=NATIVE and the matching provider configuration.

lie-agent --build-info reports the variant. The runtime --backend option and former environment override are removed. Session continuation requires the matching binary. Model paths, endpoint and generation limits remain settings of the relevant variant.

Model loading is lazy in a NATIVE session and the model stays resident between messages. Check model compatibility. Both compiled variants have completed controlled original-model acceptance. Earlier runtime-switching archives remain historical.

Tools and recovery

Read, list and search files, inspect Git, patch content and run bounded commands. Reads are available by default; --allow-write and --allow-command grant the corresponding effects for that invocation. C validates tool arguments, permissions and durable outcomes.

Inspect interrupted work with effects SESSION_ID. Record an explicit resolution with reconcile SESSION_ID --report FILE before continuing uncertain effects.

State lives under $XDG_STATE_HOME/synapse/lie-agent or $HOME/.local/state/synapse/lie-agent. Use --state-dir for a private absolute root. Removal and retention reclaim settled, ownerless state.

Extensions

TypeScript plugins

An external Node 22.23.0 runner loads explicitly installed, trusted plugins: tools, typed hooks and context contributions. The C core applies policy after hook rewrites.

MCP client

Configured stdio and Streamable HTTP peers expose tools, resources and prompts. Credentials stay outside prompts and journals. MCP server mode is outside the plan.

CodeMode

The optional pinned Pi / QuickJS-WASI component composes registry calls in JavaScript. Nested C, TypeScript and MCP calls retain their own permissions and durable effect identities.

Context, discovery and events

Project instructions, plugin contributions and tool results enter a budgeted context. Preflight token counts are estimates. Compaction preserves original history; summary requests consume the same run budget.

Optional finite mDNS scans discover candidate LIE endpoints. Choosing a remote peer requires readiness and model checks. --jsonl emits structured events; --observe enables authenticated loopback SSE with snapshots and bounded replay.

Availability

The first private alpha is integrated in the local development tree. The owner-authorized private installation passes operational postflight. Public source integration and package downloads remain pending.

Six private component archives are assembled from the newly qualified REMOTE/NATIVE binaries. Each variant has its own identity and embedded acceptance record. The private target has fixed REMOTE/NATIVE launchers and separate profiles; installation starts no model or inference service. Public downloads remain pending.

Validation scope

Both current variants pass eight controlled C17 task cases under the approved final-correctness and cost criterion. The final source, compiler and tests must be correct; corrective patches count toward cost. Model qualification describes this profile and these tasks.

Recorded target and test limits

Linux x86_64, immutable Fedora43/ROCm image, gfx1150 and original Qwen3.8-Flash-Next UD-Q4_K_XL. Eight successful C17 cases: two tasks, individual/CodeMode, native/HTTP. Seven also satisfy the previous single-patch criterion; the original HTTP failure remains recorded. Total cost: 9 successful patches, 33 requests and 87,967 observed prompt/completion tokens. Context 8192, chunk 2048, output 1024, C1, no MTP or vision.

Both variants pass actual-model tmux detach, continuation and same-owner reattach using TERM=linux PTYs. The installed private launchers also pass two owned SSH closures, same-folder session selection and same-owner reattach. Nine ticket/ownership tests cover their client cleanup; portable C archives remain unchanged. Physical VT, last-global-SSH logout and physical persistent-media power loss were outside acceptance. The full archive requires ICU77, absent on the unmodified Pop!_OS host.

The two fixtures establish no general speed or coding-ranking claim. CPU acceptance covers 73 distinct REMOTE and 89 distinct NATIVE cases across retained runs and corrections, a full 89-case sanitizer baseline, and focused final checks.

Later work

LA13 has started in a separate development branch: a C17 read-only HTTP/2/Protobuf capability probe passes 31 normal and 31 ASan/UBSan cases. It is excluded from alpha packages. Authentication, TLS, reactor lifetime and cancellation/retirement remain before product integration. Continuous discovery, connected-agent liveness, numerical checkpoints, session branches, LSP, browser and GUI follow later.
