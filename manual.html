Strix Halo · build once
make strix-halo

This creates build/strix-halo/. On Strix Point, use make strix-point and replace that path with build/strix-point/. The build does not download model weights.

Looking for a particular flag? The searchable option reference keeps every server and benchmark setting in one place.

The documented model is Unsloth Qwen3.8 Flash Next UD-Q4_K_XL. Keep all four GGUF shards together and pass the first shard to the loader. The weights are downloaded separately.

Run the server

Start the model

The model loads after process start. The API listens on port 8000; the management listener defaults to loopback port 19880. Keep the terminal open while serving.

Terminal 1 · from repository root
LIE_MODEL=/path/to/Qwen3.8-Flash-Next-UD-Q4_K_XL-00001-of-00004.gguf
build/strix-halo/synapse-lie-server \
  --model "$LIE_MODEL" --model-id qwen3.8-flash-next \
  --host 127.0.0.1 --port 8000 --context 262144 --max-active 1

Wait for readiness, then check that the model ID is listed. Readiness means the model and executor opened; it is not a quality or performance certificate.

Terminal 2 · readiness and model list
curl --fail http://127.0.0.1:19880/actuator/health/readiness
curl --fail http://127.0.0.1:8000/v1/models

For a client on another machine, use --host 0.0.0.0 and point it at http://SERVER-IP:8000/v1. The server has no built-in authentication or TLS, so use a trusted network or a configured proxy. Stop the foreground process with Ctrl+C.

Your first response

Send a request

Use the --model-id value in each request. Chat Completions and Responses are both available; clients execute function tools and send the resulting messages back to the API.

Chat Completions

A normal response. Add "stream":true to the body and --no-buffer to curl for SSE streaming.

POST /v1/chat/completions
curl --fail http://127.0.0.1:8000/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen3.8-flash-next","messages":[{"role":"user","content":"Explain a KV cache."}],"max_tokens":128,"temperature":0}'

Responses

store:false keeps this example stateless, useful for independent runs.

POST /v1/responses
curl --fail http://127.0.0.1:8000/v1/responses \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen3.8-flash-next","input":"Write a short greeting.","store":false,"max_output_tokens":128,"temperature":0}'

For tool calls, stored responses, streaming details and supported fields, see the API contract.

When prompts get longer

Context, users and saved state

1,048,576Maximum configurable context tokens per sequence; real GPU fit and quality need their own check.
1–8Active sequences via --max-active; ready decode requests can be batched.
4 GiBDefault RAM KV-retention budget; disk persistence is off by default.

--prefill-chunk 2048 bounds prompt tokens handled in one dispatch; the configurable range now reaches 32,768. The prompt, chat template and requested output must all fit inside --context. Beyond the model’s native context, choose an explicit YaRN profile. Long prompts and more active users need more memory.

Disable RAM checkpoint reuse for a cold-prompt measurement with --kv-cache-ram-mb 0. To keep reusable KV checkpoints on disk, add all three options below to the server start command. The parent directory must already exist; LIE creates its private child directory.

Optional server flags · persistent KV
--kv-disk-dir /absolute/path/to/lie-cache \
--kv-disk-space-mb 16384 --kv-disk-staging-mb 8192

These options retain inference state, not model weights. For cache policy and budget details, see the server guide.

Use an agent

Connect Pi over HTTP

The agent client guide contains the complete Pi models.json and settings.json profiles, plus the current Codex and Claude Code integration status.

Develop includes a Pi OpenAI-provider profile. Copy it into a private directory, edit baseUrl in models.json to your server’s http://SERVER-IP:8000/v1, and set contextWindow to the configured context. The profile’s API key is a client placeholder, not server-side access control.

Prepare profile and launch Pi
mkdir -p run
mkdir -m 700 run/pi-profile
cp config/pi-unsloth.models.json run/pi-profile/models.json
cp config/pi-unsloth.settings.json run/pi-profile/settings.json
# Edit run/pi-profile/models.json before starting Pi.
env PI_CODING_AGENT_DIR="$PWD/run/pi-profile" PI_OFFLINE=1 PI_TELEMETRY=0 \
  pi --provider synapse-lie --model qwen3.8-flash-next --thinking off \
  --no-extensions --no-skills --no-prompt-templates --no-themes

Measure the model

Run a benchmark

The native C benchmark saves raw measurements as JSONL. Direct suites run the model executor without HTTP; HTTP suites need an already running server. Pick a new output filename for every run: the tool refuses to overwrite evidence.

Common setup · GPU build on develop
LIE_BENCH=build/strix-halo/synapse-lie-bench
LIE_MODEL=/path/to/Qwen3.8-Flash-Next-UD-Q4_K_XL-00001-of-00004.gguf
mkdir -p results
1Prefill · PP

How quickly the model reads the input prompt. Reported in prompt tokens per second.

→
2Decode · TG

How quickly it generates the reply. Reported in output tokens per second.

A cache hit may skip executed prefill. In multi-user results, aggregate output rate and the sum of individual decode rates use different denominators; compare the same metric across runs.

Choose a question

Pick the right workload

How fast is a full prompt?Use fresh. It starts with empty state and measures the whole prompt.
What happens after 32K?Use single. It adds a new suffix after an occupied prefix.
How do several users share decode?Use multi. Prepared sequences decode together at C1–C8.
What does the shared engine do?Use core for admission, cache and per-job timing.
What does an API caller see?Use http against a running server.
What about concurrent API calls?Use http-multi for prepared HTTP cohorts.

For a growing context, two additional suites answer different questions: ds4-walk appends fixed raw-text token steps inside the executor; http-curve follows the canonical cached conversation protocol over HTTP. Their rates are not interchangeable with full cold-prompt prefill.

Measure a fresh 8K prompt

The fresh suite measures full prompt prefill from an empty sequence. It is the direct choice when you want to avoid mixing prefix construction or cache reuse into the number.

Direct executor · fresh prompt
"$LIE_BENCH" --model "$LIE_MODEL" --suite fresh \
  --sizes 8192 --tg 128 --warmups 0 --repetitions 3 \
  --output results/fresh-8k.jsonl

Measure occupied context and concurrent decode

These direct suites answer different questions. single times about 2,048 new tokens after each existing depth; multi prefills every sequence before timed decode. Neither measures HTTP latency.

Direct executor · depth and C1–C8
"$LIE_BENCH" --model "$LIE_MODEL" --suite single \
  --depths 0,4096,8192,16384,32768,65536,131072 \
  --pp 2048 --tg 128 --warmups 1 --repetitions 3 \
  --execution reactive --output results/single.jsonl

"$LIE_BENCH" --model "$LIE_MODEL" --suite multi \
  --users 1,2,4,6,8 --pp 2048 --tg 128 \
  --warmups 1 --repetitions 3 --execution reactive \
  --output results/multi.jsonl

For a custom UTF-8 prompt, use --suite core --prompt-file prompt.txt --context 32768 --chunk 2048 --users 1 --tg 128. Add --kv-cache-ram-mb 0 for cold execution and a new --output file. See the core benchmark guide for the full command and cache-controlled comparison.

Client-visible performance

Measure the HTTP path

Start the server first. The canonical http-curve workload grows one conversation across context depths, then measures a new turn at each depth. The server needs enough context and RAM prefix retention; the command only measures it and does not change its configuration.

Growing conversation · running server required
"$LIE_BENCH" --suite http-curve \
  --url http://127.0.0.1:8000/v1 --model qwen3.8-flash-next \
  --depths 0,4096,8192,16384,32768,65536,131072 \
  --pp 2048 --tg 128 --context-capacity 262144 \
  --warmups 1 --repetitions 3 --server-label LIE \
  --output results/lie-curve.jsonl

Each point measures newly added prompt tokens, not the entire accumulated prefix. To measure one cold 131K prompt, use fresh --sizes 131072 or a cache-off http request. Read the curve method before comparing another engine.

Show a cold HTTP prefill example ⌄
Full prompt from an empty server state
"$LIE_BENCH" --suite http \
  --url http://127.0.0.1:8000/v1 --model qwen3.8-flash-next \
  --preset prefill --sizes 1500,8000,32768,131072 \
  --tg 128 --warmups 0 --repetitions 3 --server-kv-cache off \
  --server-label LIE --output results/http-prefill.jsonl \
  --export-requests results/http-requests.jsonl

For that cold example, start the server with --kv-cache-ram-mb 0 and no disk cache. --server-kv-cache off is a declaration in the benchmark record; it cannot clear the server cache.

For prepared C1–C8 HTTP cohorts, use --suite http-multi with a request corpus, a server configured for the needed active slots, and cache capacity that retains the prepared prefixes. The source guide includes the pinned corpus and exact command.

Read the result

Export graphs and tables

The offline report reads saved JSONL without loading the model. Its output directory must be new. A successful export contains benchmark.svg, benchmark.png, summary.csv and summary.json; Python and Matplotlib are not required.

Offline report · no GPU model load
"$LIE_BENCH" --suite report results/lie-curve.jsonl \
  --output results/lie-curve-charts --label 'LIE'

Preserve the JSONL beside the graph: it contains the individual runs and identity needed to assess the chart. The report shows phase rates separately and refuses incomplete or inconsistent evidence. A failed export leaves the raw file available.

If something fails

Find the cause

Readiness is 503

Wait for model loading, check the server log, model path and HIP-enabled build. An empty model list does not mean inference works.

Context request is rejected

Include chat-template and output tokens in the budget, or reduce the input. Above native context, select a YaRN profile and check memory fit.

No graph appears

Check the report exit code and raw JSONL. Use a new output directory; invalid or incomplete measurements are rejected.
